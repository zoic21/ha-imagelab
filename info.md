# Image Lab

Outils d’analyse locale d’images pour Home Assistant. Les premiers modules prévus permettent de comparer une capture à des images de référence et d’extraire les couleurs dominantes d’une image.

**Socle de développement.** Le dépôt permet de tester la distribution via HACS. Le panneau de configuration et les modules d’analyse seront ajoutés lors des prochaines étapes.

[Architecture et feuille de route](https://github.com/zoic21/ha-imagelab#readme)
