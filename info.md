# Image Lab

Outils d’analyse locale d’images pour Home Assistant. Les premiers modules prévus permettent de comparer une capture à des images de référence et d’extraire les couleurs dominantes d’une image.

Comparez des captures de caméra ou des images importées à vos références. Extrayez aussi une palette depuis une pochette, une caméra ou une image importée. Le panneau affiche les couleurs et l’action `image_lab.analyze` renvoie les valeurs RGB pour les automatisations.
